Doctor Listing Destination Page – Project Overview
This project is a Next.js + Spring Boot clone of the Apollo247 General Physician listing page. It demonstrates how to build an SEO-optimized, filterable doctor listing interface powered by a SQL-backed REST API.

Technologies User:
1.Frontend: Next.js (App Router), Tailwind CSS
2.Backend: Spring Boot (REST APIs)
3.Database: SQL (e.g., MySQL)

Features:
1.Doctor listing page with filters (gender, experience, fee, rating)
2.Pagination support via API
3.SEO meta tags (title, description, canonical)
4.Modular components: Header, DoctorCard, FilterPanel
5.REST APIs:
    1.POST /api/doctors/add – Add a new doctor
    2.GET /api/doctors – List doctors with filters & pagination
